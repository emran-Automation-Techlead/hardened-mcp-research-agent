## Observations
- Both AWS and Azure are emphasizing AI/ML, data, and compute infrastructure. Many posts highlight AI-enablement, new models/services, and improved infrastructure for AI workloads.
- Azure’s recent posts emphasize agentic AI and enterprise integration, aligning with Microsoft's Copilot/agent-centric strategy and hardware advances.
- AWS is releasing serverless GPU compute, enhanced emulation, and broader developer/DevTools updates. Much emphasis is placed on removing friction for engineers and making advanced workloads easier.
- Security and platform reliability are explicitly reported in recent Azure and some AWS posts.

## Limitations
- Categories are assigned based on blog post descriptions/headlines only; deeper analysis would need the full article.
- Source list reflects each provider's own blog highlight selection (potential bias to their recent launches or themes).
- Azure post URLs and headlines were taken directly from the latest homepage text.
- Not all posts fit a single category perfectly; only the broad primary theme is given here as required.
